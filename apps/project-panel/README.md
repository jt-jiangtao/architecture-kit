# 项目执行面板

在 Kit 根运行 `pnpm project:panel /absolute/project`（或在相邻的消费仓库根运行 `pnpm project:panel`）。打开终端打印的本机地址，默认端口 `4318`，可通过 `PROJECT_PANEL_PORT` 指定端口。`/playground` 是共享面板的固定组件预览。

服务仅绑定回环地址，只读启动时指定工作区的 `openspec/changes`。前端使用自包含的无外部仓库依赖组件与语义化亮/暗色 CSS tokens，不依赖任何下游产品包。每三秒重读，断开时保留上次快照。变更的任务数量直接来自 `tasks.md` 的 Markdown 清单。需要补充任务级状态时，可在对应条目下记录，例如：

    - [ ] 2.1 核对项目接入
      > 执行状态：等待输入 | 2026-11-18T15:00:00+08:00 | 待指定目标项目 | 收到目标目录

进行中、等待输入和阻塞共用此格式，解除条件可省略。恢复后原位改回进行中并更新时间；勾选的任务优先显示为完成。单个变更读取失败仅影响该变更，服务失联会显示最近成功同步时间。该记录的时间来自执行者，页面的同步时间来自浏览器。

模块入口为 `src/server.ts`，`src/snapshot.ts` 解析项目数据，`src/runtime-port.ts` 定义可注入的 `RuntimeProvider` 端口；`ui/Panel.tsx` 通过注入的 `ProjectSource` 同时服务真实项目和预览。

列表默认展示未完成的未归档变更。“显示已完成”可查看仍在活动目录中的完成项。归档目录始终排除，已归档变更的旧链接回到可见变更。

当前执行总览自动汇集各未归档变更中明确记录为进行中、阻塞或等待输入的任务。总进度按这些变更已完成任务数之和除以任务总数之和计算。同一变更的多个并行任务共用一个进度分母。

## 执行运行时状态与通用 Issue 关联

服务通过注入的 `RuntimeProvider` 读取运行时状态；默认提供 `createCodexRuntimeProvider`，在每次快照读取时从 `CODEX_HOME`（默认 `~/.codex`）只读查询 `state_5`、`thread_history_1` 和 `goals_1` SQLite 投影。按工作目录与未归档会话筛选，用最新回合和 `lsof` 查询的打开写入句柄确认进行中的会话，并显示目标阻塞、额度限制、回合失败及投影可识别的输入请求。普通工具失败不等于整项任务阻塞。终止或恢复后下一次成功读取即更新。

会话按目标原文中的唯一变更名或 `<PREFIX>-<NUM>` issue 编号关联（默认匹配 `[a-z]{2,10}-\d+`，如 `ACT-12`、`ENG-45`，可通过 `PROJECT_PANEL_ISSUE_PATTERN` 覆盖）；无有效目标时使用会话标题。缺少唯一关联时单列项目会话。清单百分比按关联变更去重，另列运行时工具操作完成数和最近公开反馈。无结构化记录的业务卡点可补充在 `tasks.md`。服务仅向本机面板返回这些投影，不返回工具输入输出或推理记录。数据库不兼容、不可读或运行环境缺少 `lsof` 时显示来源错误。

首页展示执行总览，变更详情使用 `?change=` 标识。桌面端导航和内容区独立滚动，切换变更时详情回到顶部。窄屏使用顶部项目导航切换视图。列表长名称最多两行，进入详情显示完整名称；会话反馈默认单行，展开查看全文。

执行总览标题优先展示明确关联的当前中文任务。只有变更级关联时，使用提案的中文一级标题，缺失时读取提案首个能力的主规格中文标题或提案里的中文说明。悬停可读完整名称和变更标识。
